GesturePDF – Technical Overview & Architecture

Real-time client-side computer vision & deterministic gesture engine

PROJECT LEAD & ARCHITECT

1. Project Overview

GesturePDF is a completely browser-based, touchless presentation tool enabling frictionless PDF navigation via webcam-based computer vision. Everything runs client-side with zero latency and strict privacy (no video streaming to external servers).

2. Core Technology Stack

  • Google MediaPipe Hands API: Real-time 21 3D hand skeletal landmark extraction.
  • Mozilla PDF.js: Client-side PDF parsing and vector rasterization.
  • HTML5 Canvas 2D API: Dynamic coordinate radar and math slide rendering.
  • Hardware Accelerated CSS3 Transforms: 60 FPS viewport manipulation via GPU matrix transforms (`scale`, `translate3d`).
  • Web Storage API: Persistent configuration storage for axis inversions and sensor gains.

3. Mathematical Foundations & Gesture Logic

Unlike probabilistic gesture classifiers that suffer from high false-positive rates, GesturePDF uses deterministic spatial geometry and threshold mathematics:

A. Euclidean Distance Metric
d(p₁, p₂) = √[(x₂ - x₁)² + (y₂ - y₁)²]

Applied to normalize coordinates across varying webcam aspect ratios and distances from camera.

B. Finger Extension Detection
isExtended(tip, pip) = d(LM_tip, LM₀) > 1.12 × d(LM_pip, LM₀)

Measures the distance from wrist root (LM₀) to fingertip versus the proximal interphalangeal joint (PIP). Evaluated across index (8), middle (12), ring (16), and pinky (20).

C. Strict Pinch Detection (Anti-Fist Math)
Pinch_Ratio = d(LM₄, LM₈) / Hand_Scale < 0.38 Hand_Scale = d(LM₀, LM₉) Condition = Pinch_Ratio && !middle && !ring && !pinky

A closed fist is completely rejected because index and thumb ready-extension gates must be verified while the remaining 3 fingers stay folded.

D. Zoned Screen Partitioning (Page Turning)
x_screen = 1 - [(LM₄.x + LM₈.x) / 2] Zone = { Previous: x < 0.24, Next: x > 0.76, DeadZone: 0.24 ≤ x ≤ 0.76 }

The viewport center 52% is an inactive dead-zone to prevent accidental page triggers during gestures. Latches via single-shot flag (`pinchTriggered`) to prevent multi-page runaway flips.

E. Exponential Moving Average (EMA) & Jitter Filter
S_t = S_{t-1} + α · (X_t - S_{t-1}) [α = 0.20 for Zoom, 0.30 for Pan] Delta_Threshold: |Δ| > 0.006

Suppresses camera sensor noise, micro-jitters, and hand tremors without inducing motion lag.

F. 2.0s Temporal Pinky Safety Lock
Δt = t_now - t_pinky_start ≥ 2000 ms (Pose == 'pinky' only)

Allows presenters to talk freely with natural hand movements by toggling a complete gesture lockout state.

4. High-Performance PDF Rendering

  • Pre-Rasterized Backing Canvas: Avoids PDF canvas re-render calls on zoom/pan gestures, eliminating screen freezing and white flashes.
  • Async Render Locks: Promise-based render queue (`busy` & `again` flags) manages rapid page flips without race conditions.
